# UpdateFit
 
## Descripción
 
UpdateFit es una web que ayuda a las personas que quieren empezar a cuidarse pero no saben por dónde empezar. Reúne planes de entrenamiento, consejos de nutrición y hábitos saludables explicados de forma sencilla.
 
Está pensada para principiantes que buscan cambios pequeños y fáciles de mantener, con planes adaptados a cada persona y un seguimiento cercano.
 
## Estructura del Prototipo
 
Todas las páginas comparten un menú de navegación en la cabecera para moverse entre ellas.
 
* **index.html:** Página principal con la presentación de UpdateFit y enlaces a cada sección.
* **training.html:** Formulario para elegir entre los planes Básico, Completo y Pro.
* **nutrition.html:** Consejos de alimentación con imágenes.
* **healthy-habits.html:** Hábitos saludables con imágenes.
* **about.html:** Historia y valores del proyecto, con un vídeo.
* **contact.html:** Formulario de contacto.

## Tecnologías Utilizadas
 
* HTML5
* CSS3

## Enfoque Técnico
 
* Diseño Mobile First con `@media (min-width: 768px)`.
* Selectores de etiqueta, clase, id y combinados (por ejemplo, `.plan input`).
* Display: `flex`, `grid`, `block` e `inline-block`.
* Position: `sticky`, `relative` y `absolute`.
* Efectos `hover` en enlaces, botones y tarjetas.
